Information Design

International Timeline of Events

This project translates a broad set of international events into a single readable visual system. The emphasis was on chronology, hierarchy, and pacing rather than decoration.

It was a useful exercise in making dense content accessible, using spacing and structure to help a viewer move through complexity without friction.

Focus Hierarchy, chronology, and information clarity
Medium Large-format visual timeline
Goal Make complex sequences understandable at a glance

What the project tests

Information design has a lot in common with engineering communication. Both depend on order, compression, and knowing what to foreground. This timeline was built with that in mind, using layout to support understanding rather than competing with it.

Primary concerns

  • Chronological flow without visual crowding
  • Legible hierarchy across many events
  • A single frame that still rewards close reading
