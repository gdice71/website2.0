1st Year Connect 4 Robot

This first-year project brought together programming, mechanical assembly, sensing, and game interaction in one compact system. The goal was not only to build a working robot, but to understand how separate engineering decisions compound in a single physical object.

It became a practical introduction to system thinking: structure, logic, movement, and reliability all had to align for the project to work.

Focus Introductory robotics and game-playing system design
Tools C++, mechanical assembly, sensors
Outcome A working interactive robot with autonomous decision logic

Systems over parts

What made this project valuable was the way it tied disciplines together. Mechanical design on its own was not enough, and neither was code. The robot only became convincing when those decisions started reinforcing one another.

That kind of integration is what still makes the project worth keeping in the archive.

Core pieces

  • Mechanical structure and motion path planning
  • Programming for decision flow and interaction
  • Sensor integration and reliability under simple constraints
