Full-Stack Web App

UW Engineering Help Desk System

This project was built for the University of Waterloo First-Year Engineering office to replace a manual student-visit workflow with a structured internal web app. Staff needed a faster way to log visits, review demand patterns, and keep the data exportable for follow-up and reporting.

I built the system in Flask with SQLite, authentication, and CSV export, then shaped the interface around the office's day-to-day workflow. The result is a production tool that supports real student traffic instead of a one-off demo.

Focus Internal visit logging and analytics for first-year engineering support
Stack Flask, SQLite, authentication, CSV export, dashboard UI
Outcome Used in production by the First-Year Engineering office

Built around an office workflow

The app was designed for speed and clarity. Staff can create academic terms, log sessions against course and program context, and immediately review demand through a dashboard instead of piecing together activity by hand.

That framing mattered more than surface polish alone. The system had to be easy to use during busy office hours, reliable enough for repeated daily use, and structured enough to produce useful records afterward.

Key capabilities

  • User authentication for controlled internal access
  • SQLite-backed visit logging tied to term and course data
  • Dashboard views for totals, help rates, and usage patterns
  • CSV export for downstream reporting and record keeping
